==== POSTMAN API TESTING GUIDE ====

== Login User ==============================
URL: http://localhost:3000/login_user
Method: POST
Headers: Content-Type: application/json
Body:
{
  "email": "test1@test.com",
  "password": "1234"
}
======================================


== Register User ==============================
URL: http://localhost:3000/register
Method: POST
Headers: Content-Type: application/json
Body:
{
  "name": "Test User",
  "nickname": "Tester",
  "email": "test1@test.com",
  "password": "123456"
}
======================================


== Create League ==============================
URL: http://localhost:3000/create_league
Method: POST
Headers:
Content-Type: application/json
Authorization: Bearer YOUR_JWT_TOKEN
Body:
{
  "name": "Premier League 2025",
  "points_for_win": 3,
  "points_for_draw": 1,
  "points_for_win_margin": 1,
  "points_for_close_loss": 1,
  "win_margin_threshold": 15,
  "play_each_other": 2,
  "start_date": "2025-05-01",
  "end_date": "2025-08-31"
}

Response will include a unique 4-digit public_code and active=true
======================================

== Get User Leagues ==============================

Method: POST
Headers:
Content-Type: application/json
Authorization: Bearer YOUR_JWT_TOKEN
Body:
{}

======================================

== Generate Fixtures ==============================
URL: http://localhost:3000/generate_fixtures
Method: POST
Headers:
Content-Type: application/json
Authorization: Bearer YOUR_JWT_TOKEN
Body:
{
  "league_id": 1
}

Generates fixtures for all members of the league based on play_each_other setting
Only the league creator can generate fixtures
======================================

== Get League Fixtures ==============================
URL: http://localhost:3000/get_league_fixtures
Method: POST
Headers:
Content-Type: application/json
Authorization: Bearer YOUR_JWT_TOKEN
Body:
{
  "league_id": 1
}

Retrieves all fixtures for a specific league with player details
Only league members or the creator can access fixtures
======================================

== Update Fixture Score ==============================
URL: http://localhost:3000/update_fixture_score
Method: POST
Headers:
Content-Type: application/json
Authorization: Bearer YOUR_JWT_TOKEN
Body:
{
  "fixture_id": 1,
  "player_1_score": 3,
  "player_2_score": 2
}

Only the league creator or the players involved can update the score
======================================

== Get League Info ==============================
URL: http://localhost:3000/get_league_info
Method: POST
Headers:
Content-Type: application/json
Authorization: Bearer YOUR_JWT_TOKEN
Body:
{
  "league_id": 1
}

Response example:
{
  "return_code": "SUCCESS",
  "league": {
    "id": 1,
    "name": "Premier League 2025",
    "created_by": 123,
    "public_code": "1234",
    "active": true,
    "start_date": "2025-05-01",
    "end_date": "2025-08-31",
    "created_at": "2025-04-06T12:00:00.000Z",
    "is_creator": true,
    "points_for_win": 3,
    "points_for_draw": 1,
    "points_for_win_margin": 1,
    "points_for_close_loss": 1,
    "win_margin_threshold": 15,
    "play_each_other": 2,
    "win_type": "POINTS"
  }
}

Retrieves detailed information about a specific league
Only league members or the creator can access the league info

== Authentication Header Format ==============================
For authenticated routes, add this header:
Authorization: Bearer YOUR_JWT_TOKEN
======================================

== Common Response Codes ==============================
SUCCESS - Operation completed successfully
MISSING_FIELDS - Required fields are missing
INVALID_CREDENTIALS - Email or password is incorrect
EMAIL_ALREADY_EXISTS - Email is already registered
INVALID_CODE - The provided public code is invalid
LEAGUE_INACTIVE - The league is not active
CODE_GENERATION_FAILED - Failed to generate a unique code
SERVER_ERROR - Server encountered an error
UNAUTHORIZED - Authentication token is missing or invalid
======================================
