==== POSTMAN API TESTING GUIDE ====

== Get App Version ==============================
URL: http://localhost:3000/get_app_version
Method: POST
Headers: Content-Type: application/json
Body:
{
  "platform": "android"
}

Notes:
- Returns the minimum required app version for the specified platform
- Valid platforms are those defined in the app_version_requirement table
- Response includes platform and minimum_version
======================================

== Login User ==============================
URL: http://localhost:3000/login_user
Method: POST
Headers: Content-Type: application/json
Body:
{
  "email": "test1@test.com",
  "password": "1234"
}

Notes:
- Login will fail with EMAIL_NOT_VERIFIED if the user's email is not verified
- Use the verify_email API to verify the email before logging in
======================================

== Create League ==============================
URL: http://localhost:3000/create_league
Method: POST
Headers:
Content-Type: application/json
Authorization: Bearer YOUR_JWT_TOKEN
Body:
{
  "name": "Premier League 2025",
  "win_type": "PTS",
  "points_for_win": 3,
  "points_for_draw": 1,
  "points_for_win_margin": 1,
  "points_for_close_loss": 1,
  "win_margin_threshold": 15,
  "play_each_other": 2,
  "start_date": "2025-05-01",
  "end_date": "2025-08-31"
}

Win Type Options:
- "PTS": Points-based scoring (like Snooker)
- "WIN": Win-only scoring (like Pool)
- "WDL": Win/Draw/Loss scoring (like Football)

Response will include a unique 4-digit public_code and active=true
======================================

== Update Fixture Score ==============================
URL: http://localhost:3000/update_fixture_score
Method: POST
Headers:
Content-Type: application/json
Authorization: Bearer YOUR_JWT_TOKEN

1. For Points-based leagues (win_type="PTS"):
Body:
{
  "fixture_id": 1,
  "player_1_score": 3,
  "player_2_score": 2
}

2. For Win-only leagues (win_type="WIN"):
Body:
{
  "fixture_id": 1,
  "result": "WIN_1"  // or "WIN_2"
}

3. For Win/Draw/Loss leagues (win_type="WDL"):
Body:
{
  "fixture_id": 1,
  "result": "WIN_1"  // or "WIN_2" or "DRAW"
}

Updates the score for a specific fixture based on the league's win_type
Only the league creator or the players involved can update the score
======================================

== Remove Player From League ==============================
URL: http://localhost:3000/remove_player_from_league
Method: POST
Headers:
Content-Type: application/json
Authorization: Bearer YOUR_JWT_TOKEN
Body:
{
  "league_id": 1,
  "player_id": 2
}

Allows a league organizer to remove a player from their league
Will fail if fixtures have already been generated
Only the league creator can remove players
Organizers cannot remove themselves from the league
======================================

== Common Response Codes ==============================
SUCCESS - Operation completed successfully
MISSING_FIELDS - Required fields are missing
INVALID_CREDENTIALS - Email or password is incorrect
EMAIL_ALREADY_EXISTS - Email is already registered
INVALID_CODE - The provided public code is invalid
LEAGUE_INACTIVE - The league is not active
CODE_GENERATION_FAILED - Failed to generate a unique code
FIXTURES_EXIST - Cannot perform operation because fixtures already exist
PLAYER_NOT_FOUND - The specified player was not found
INVALID_OPERATION - The requested operation is not allowed
SERVER_ERROR - Server encountered an error
UNAUTHORIZED - Authentication token is missing or invalid
INVALID_TOKEN - The provided token is invalid
TOKEN_EXPIRED - The provided token has expired
EMAIL_NOT_FOUND - No user found with the provided email
INVALID_PASSWORD - The provided password is incorrect
ALREADY_VERIFIED - Email is already verified
======================================
